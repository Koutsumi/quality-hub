🚀 Modern Dev Portfolio | React + Tailwind + Framer Motion

Este é o repositório do meu portfólio profissional de alto impacto. Desenvolvido com uma estética Dark Mode/Glassmorphism, o projeto foi projetado para oferecer uma experiência imersiva enquanto apresenta minha trajetória como desenvolvedor e especialista em QA.

🔗 Acesse o projeto vivo aqui: [Link do seu Lovable/Deploy]
🎨 Diferenciais do Projeto

    Design Futurista: Interface baseada em cartões com bordas iluminadas (Glow), efeitos de vidro e tipografia refinada.

    Seção de Projetos Dinâmica: Destaque especial para o Central QA, com fluxos de trabalho detalhados e métricas.

    Totalmente Responsivo: Adaptado para leitura perfeita em desktops, tablets e smartphones.

    Performance Extrema: Construído sobre o Vite para garantir carregamento instantâneo e transições fluidas.

🛠️ Tecnologias de Elite

O portfólio utiliza o que há de mais moderno no ecossistema Frontend:

    Vite + React (TypeScript): Performance e tipagem segura.

    Tailwind CSS: Estilização utilitária com foco em customização profunda.

    Shadcn/UI: Componentes de interface acessíveis e altamente polidos.

    Lucide React: Iconografia consistente e minimalista.

    Framer Motion: Animações de entrada e interações suaves que guiam o olhar do usuário.

📂 Estrutura do Site

    Hero Section: Introdução impactante com foco em conversão.

    Tech Stack: Grid visual das ferramentas que domino (Node, React, Docker, etc).

    Projetos em Destaque: Vitrine detalhada de aplicações reais (como o Central QA).

    Experiência Profissional: Linha do tempo limpa e organizada.

    Contato: Seção direta para networking e propostas.

🐳 Rodando com Docker

Se você deseja rodar este portfólio localmente em um ambiente isolado:

    Suba o container:
    Bash

    docker compose up -d

    Acesse em:
    http://localhost:5173

📝 Notas de Desenvolvimento

Este projeto foi estruturado para ser facilmente escalável. Se quiser adicionar um novo projeto, basta editar o array de dados no componente correspondente, e a interface se ajustará automaticamente graças à arquitetura de componentes reutilizáveis.
